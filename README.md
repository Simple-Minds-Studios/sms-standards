# Simple Minds Studios Brand Bible

**Version 0.1 — Working Draft**

This document defines how Simple Minds Studios should look, sound, move, and feel.

It is not intended to produce identical work.

It exists to create continuity across different forms of curiosity.

The studio may move between astronomy, human assessment, architecture, local history, grief, photography, artificial intelligence, infrastructure, fashion, and speculative design.

The subject may change.

The underlying presence should remain recognizable.
